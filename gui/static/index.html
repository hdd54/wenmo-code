      📖 说明书

      问墨·code 使用手册（v1.0.1）· 遇到问题先看这里

      一、快速开始

      1. 顶部下拉选择一个供应商（如 DeepSeek / 通义 / 本地 Ollama）
      2. 打开设置 → 供应商 → 填入该家的 API Key 并保存
      3. 在输入框直接提问即可。输入 /help 查看可用命令

      二、供应商与模型

      内置 9 家供应商：DeepSeek、Zen、OpenCode Go、本地 Ollama、通义、智谱、硅基流动、Kimi、豆包。
      · Key 只保存在本机服务器（providers.json），浏览器看不到
      · 本地 GGUF 模型：把 llama-server.exe 放入 llama/ 目录，在供应商页选「本地」加载
      · 模型与上下文页可配置图像模型、自定义模型与上下文长度

      三、MCP 工具服务器

      MCP 把工具交给 AI 调用：网页搜索、文件系统、浏览器自动化、PPT 流水线等。
      · 在「MCP、插件与技能」页查看连接状态，可刷新
      · 配置文件：mcp.json（打包版在 %APPDATA%/问墨/）

      四、技能库与插件

      · 技能库：199 个技能按 14 类组织；通用技能时刻生效，个性技能聊天时自动匹配注入
      · 插件：plugins/ 目录下的 Python 插件，工具自动交给 AI 调用
      · 小应用：内置挂件，点击右上角可全屏/关闭

      五、权限与计费

      · 权限：控制 AI 写文件 / 执行终端命令时是允许、询问还是拒绝（对标 opencode）
      · 计费：通用页「查看计费」可看所有对话费用明细，按供应商/模型/时间统计

      六、登录与更新

      · 登录：支持 GitHub OAuth 多用户登录，数据按用户隔离（需配置 GITHUB_CLIENT_ID/SECRET）
      · 更新：启动时自动检查 GitHub Releases，有新版本会提示下载
      · 数据目录：%APPDATA%/问墨/（历史、配置、文件都在这里，卸载不丢数据）

      七、常见问题

      · 供应商列表为空？确认 providers.json 存在于数据目录（打包版首次启动自动引导）
      · 桌面窗口打不开？查看 %APPDATA%/问墨/webview_error.log
      · 需要联网工具？确认 websearch MCP 已连接
